## Project Description

This project implements nine technical analysis indicators using base R functions without external libraries.

The indicators are used to analyze financial data, identify trends, measure volatility, and detect potential trading signals.

## Implemented Indicators

1. Simple Moving Average (SMA)
2. Exponential Moving Average (EMA)
3. Moving Average Convergence Divergence (MACD)
4. Standard Deviation
5. Linear Regression
6. Relative Strength Index (RSI)
7. Stochastic RSI
8. Crossover
9. Crossunder

## Testing

The test_indicators.R script contains sample data and checks the calculations.

## How to Run

1. Open Posit Cloud or RStudio.
2. Download the R scripts into the same folder.
3. Set the working directory to that folder.
4. Run the following command:

```r
source("test_indicators.R")
```
